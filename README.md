# بهینه‌ساز برش UPVC برای اندروید

پروژه نمونه اندروید بومی با Kotlin، بدون نیاز به اینترنت در زمان اجرا.

## امکانات
- ورود طول و تعداد قطعات به میلی‌متر؛ هر خط به شکل `1200,4` (یعنی چهار قطعه ۱۲۰۰ میلی‌متری).
- طول شاخه خام قابل تنظیم و پیش‌فرض ۶۰۰۰ میلی‌متر.
- ورودی ضخامت تیغه و دورریز مجموع ابتدا/انتهای شاخه.
- الگوریتم First-Fit Decreasing برای چیدمان قطعات و کاهش تعداد شاخه‌ها؛ این الگوریتم ابتکاری است و تضمین نمی‌کند جواب جهانی بهینه باشد.
- ذخیره سفارش‌ها در پایگاه داده SQLite محلی.
- گزارش HTML راست‌چین فارسی که با Android Print Framework به PDF قابل چاپ تبدیل می‌شود. در پنجره چاپ، گزینه Save as PDF را انتخاب کنید.

## ساخت پروژه
1. Android Studio نسخه جدید را نصب کنید.
2. از مسیر **Open** پوشه `UPVCCutOptimizer` را انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود (برای دریافت Android Gradle Plugin و Kotlin Plugin اینترنت لازم است).
4. گوشی را با USB وصل کنید یا شبیه‌ساز را اجرا کنید، سپس Run بزنید.
5. برای ساخت APK از منوی Build گزینه Build APK(s) را بزنید.

## قالب ورود اندازه‌ها
هر خط یک طول و تعداد است که با کاما جدا می‌شوند:
```
1200,4
850,3
1450,2
```
کاما فارسی، سمی‌کالن و tab هم پشتیبانی می‌شوند. ضخامت تیغه بین قطعات اعمال می‌شود (تعداد قطعات هر شاخه منهای یک). مقدار دورریز واردشده، مجموع دورریز ابتدا و انتها برای هر شاخه است.

## محدودیت‌ها و نکات
- این پروژه سورس قابل بازکردن در Android Studio است؛ APK از پیش کامپایل‌شده ارائه نشده است.
- چیدمان با روش FFD سریع و کاربردی است، اما برای تضمین بهینگی ریاضی باید الگوریتم دقیق‌تر یا حل‌گر بهینه‌سازی اضافه شود.
- پیش از استفاده تولیدی، خروجی را با چند سفارش واقعی و روش اندازه‌گیری کارگاه بررسی کنید.


## ساخت APK از طریق GitHub (بدون نصب Android Studio روی کامپیوتر)

1. در GitHub یک مخزن جدید (Repository) بسازید؛ برای نمونه `UPVCCutOptimizer`.
2. فایل‌های داخل این پوشه را در ریشه مخزن بارگذاری کنید؛ خود پوشهٔ `UPVCCutOptimizer` را به‌عنوان یک زیرپوشهٔ اضافی داخل مخزن قرار ندهید.
3. به زبانهٔ **Actions** بروید و گردش‌کار **Build Android APK** را اجرا کنید؛ یا با push کردن فایل‌ها به شاخهٔ `main` ساخت به‌صورت خودکار شروع می‌شود.
4. پس از سبز شدن اجرای workflow، همان اجرا را باز کنید و از بخش **Artifacts** فایل `UPVCCutOptimizer-debug-apk` را دانلود کنید.
5. ZIP دانلودشده را روی گوشی استخراج و فایل `app-debug.apk` را نصب کنید. ممکن است اندروید اجازهٔ نصب از منبع موردنظر را بخواهد. فقط APK ساخته‌شده از مخزن خودتان را نصب کنید.

این workflow یک APK آزمایشی (debug) می‌سازد؛ برای انتشار عمومی در فروشگاه، نسخهٔ release و امضای دیجیتال جداگانه لازم است.


## قفل ورود سالانه
- رمز ورود برنامه: `qazwsx`
- پس از ورود موفق، برنامه تا ۳۶۵ روز دوباره رمز نمی‌خواهد؛ پس از آن، رمز باید مجدداً وارد شود.
- زمان ورود روی همان گوشی ذخیره می‌شود. حذف داده‌های برنامه یا نصب مجدد می‌تواند این وضعیت را پاک کند.
- این قفل ساده برای جلوگیری از ورود اتفاقی است و امنیت رمزنگاری‌شده/سطح سازمانی محسوب نمی‌شود.
